# Prototype assembly

All populated parts are manual by explicit V0 process choice. Apply paste and reflow/hot-air0805, SOIC8, TSSOP20 and SOT23 components under magnification, inspect bridges/pin1, then solder THT headers, terminal and electrolytic. No exposed thermal-pad or via-in-pad process is used. One populated side only; through-hole tails below the carrier need≥4mm clearance/insulating standoffs. Trim sharp capacitor tails. No factory LCSC identity or rotation is invented, and no factory placement is selected. Native footprint angles and exact MPNs are in parts.json and the publisher's manual BOM.

Fit SN74LVC244APWR in U1, despite the pin-compatible bundled symbol name74HC244. HC244 would invalidate Ioff/logic calculations. U1 pin1 is at the TSSOP bevel/dot. Q1/Q2 use SO8 source1–3,gate4,drain5–8; do not rotate according to drain copper area. Q3=MMBT3904 pin1B,2E,3C; never use2N3904 TO92 pin order as the SOT23 map. U2=MCP1700T-3302E/TT pin1GND,2OUT,3IN. U3/U5=AHCT1G125; U4/U6=LVC1G17. C1 positive pad1=LOAD, stripe negative pad2=GND.

J_CTRL and J_PCA are carrier wiring hubs, not pin-compatible sockets for the modules. Use the printed labels and pinout.md. PCA V+ terminal and entire module servo V+ row remain disconnected. Only CH0–6 signal pins go to J_PCA. Keep PCA VCC=3V3, no5V I2C pull-ups, all address jumpers open for0x40. Qualify the actual module OE pull-down resistance; minimum2.4k toGND permits the1k pull-up to exceed0.7VCC (prefer nominal10k). If lower, remove that resistor and verify again. Clone identity is an assumption with this explicit modification path.

Use known FS90R-class continuous servos for six wheels and180° SG90 for turret. A180° SG90 cannot be made continuously rotating by software. Every JR connector has GND pin1,+5V middle pin2,signal pin3. Seat black/brown atGND; plug only unpowered. Bottom mounting holes have3.2mm drill and3.6mm-radius copper keepouts on both layers for centered M3 hardware. C1 measured placement is shifted0.5mm rearward from first placement to clear the reserved PCA rectangle; final STEP and native-pads.json govern integration.

Native report defaults ignored by the tile: library footprint checks, outline self-intersection, single-global-label, four-way-junction, SPICE model and footprint filters are documented in manufacturing.json's exact arrays. They are Harness defaults, never project electrical/geometric waivers. No additional check was disabled. The independent tester owns its final attestation.
