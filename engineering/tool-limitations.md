# Observed tool limits, no tool patches

- Official `verify power design/main.kicad_pro --rail LOGIC_3V3=10` does not recognize the sealed rail names LOGIC_3V3/LOAD_5V/SERVO_5V/SERVO_3V3 with its current name heuristic. It reports zero IC power pins. The board-specific audit reads actual native pads, counts all capacitors by rail, and measures every known supply pin; it does not change the official scanner or any gate. LOGIC_3V3 total1.2µF<10µF; max decoupling distance2.891mm. Report engineering/board-audit.json.
- `kicadpy.author check design/main.kicad_pro design/spec.json` reports four extra pins corresponding to deliberately unused J_CTRL12,U1 output3,U4 NC1,U6 NC1. Native KiCad exports named unconnected nets for NC marks, which the checker compares to the connected-net table. There are no missing/wrong connected pins. Official `verify netlist` compares all194 initial/200 current pins and is the authoritative parity measurement. No dummy wire was added to a silicon NC pin just to silence the helper.
- A direct standalone DRC on a candidate in build/board has library-context findings because ${KIPRJMOD}/Tank.pretty resolves relative to the candidate. The official publisher stages the project/libraries correctly and its severity-all results govern acceptance. No library or geometry finding is suppressed by these helper scripts.
- KiCad Python Remove(track) invalidated SWIG zone wrappers in the same process. Local repair scripts save after track deletion, reopen, then refill. No kicadpy/verifylib code was forked or modified.
- KiCad's generic D10 capacitor STEP was only10mm high, versus16mm for the selected part; the model was replaced by a generated manufacturer-dimension envelope. The generic fuse STEP was missing; a6.1×2.69×2.69mm envelope was added. These are physical reference envelopes, not printable parts or measured hardware.
