# Sources and provenance — checked 2026-11-20

Only this workspace, the Harness toolchain/libraries/golden block, the two explicitly authorized reference paths below, and public primary sources were read. No completed board was copied.

- Sealed PILOT_CONTRACT.json and PILOT_BRIEF.md define dimensions, connectors and GPIOs. Release notes1–2 were supplied in the repair job and are applied in order; immutable originals were not edited.
- Authorized reference `/Users/macbookpro/harnesses/crab-robot-v17g/BOM.md`: inventory only. Its prose and table disagree about LILYGO ownership; PCA and continuous servos remain assumptions.
- Authorized reference `/Users/macbookpro/harnesses/claude-pet-case/firmware/MOTION.md`: original pet/host behavior context only; firmware is another team's work.
- KiCad 10.0.5 bundled symbol/footprint libraries in the discovered application bundle; definitions copied locally, KiCad library license applies. AO4409 symbol generated from its manufacturer's pin table by tools/board/spec.py. The schematic itself is generated by unmodified kicadpy.author.
- Golden block `sg90-continuous-module/BLOCK.md`: FS90R reference dimensions, accepted logic levels and FS90 motor stall proxy (0.7A at4.8V,0.8A at6V); no hardware measurements claimed.
- [AOS AO4409 Rev8.0](https://www.aosmd.com/sites/default/files/res/datasheets/AO4409.pdf): SO8 1/2/3=S,4=G,5/6/7/8=D; 12mΩ maximum atVGS−4.5V,30V rating. AO4407A was rejected because its quoted low-R specification needs6V gate drive.
- [TI SN74LVC244A RevAG](https://www.ti.com/lit/ds/symlink/sn74lvc244a.pdf): 1.65–3.6V,5.5V tolerant inputs,Ioff protection; pin table checked against the bundled 74HC244 pin-equivalent symbol. Exact installed device is LVC, never HC.
- [Microchip MCP1700 DS20001826F](https://ww1.microchip.com/downloads/aemDocuments/documents/APID/ProductDocuments/DataSheets/MCP1700-Data-Sheet-20001826F.pdf): SOT23 1GND,2OUT,3IN; 250mA,1µF ceramic stability.
- [TI SN74AHCT1G125 RevP](https://www.ti.com/lit/ds/symlink/sn74ahct1g125.pdf): TTL VIH2V at5V,1OE/2A/3GND/4Y/5VCC; input upper limit independent of supply, only negative input clamp. No positive input-to-supply clamp is assumed.
- [TI SN74LVC1G17 RevY](https://www.ti.com/lit/ds/symlink/sn74lvc1g17.pdf): Schmitt input tolerates5.5V, Ioff supports loss of3V3; pin1NC/2A/3GND/4Y/5VCC.
- [onsemi MMBT3904LT1G](https://www.onsemi.com/pdf/datasheet/mmbt3904lt1-d.pdf):1B/2E/3C, base/gate drive and saturation design.
- [NXP PCA9685](https://www.nxp.com/docs/en/data-sheet/PCA9685.pdf): address straps, OE active low, reset output modes. [Adafruit reference module](https://learn.adafruit.com/16-channel-pwm-servo-driver/downloads) defines reference breakout family; unmeasured clones must meet the resistance checks below. The nominal10k OE pull-down and4.7k I2C pulls are explicitly reference assumptions, not claimed measurements of the owned board.
- [LILYGO pin configuration](https://raw.githubusercontent.com/Xinyuan-LilyGO/T-Display-S3/main/examples/factory/pin_config.h): parallel display occupies different pins than the old SPI pet;17SCL/18SDA. Controller stays off-carrier, wired by printed pin labels.
- [Panasonic FR catalog](https://industrial.panasonic.com/cdbs/www-data/pdf/RDF0000/ast-ind-152838.pdf): EEU-FR1A102 1000µF10V,10mm diameter,16mm high,5mm pitch,28mΩ impedance,1.79Arms rating. C1 is outside the reserved PCA module rectangle.
- [Samtec TSW103](https://www.samtec.com/products/tsw-103-07-g-s):2.54mm pitch,0.635mm square post. Separate servo contacts carry one motor each, never all7.
- [Phoenix1715721](https://www.phoenixcontact.com/en-de/products/pcb-terminal-block-mkds-15-2-508-1715721):17.5A,5.08mm pitch,1.5mm²,3.5mm tails. [Supplier listing](https://www.lcsc.com/product-detail/Screw-Terminal-Blocks_Phoenix-Contact-1715721_C480516.html) confirms identity/pitch; no stock guarantee persisted.
- [Littelfuse451 family](https://www.littelfuse.com/products/fuses-overcurrent-protection/fuses/surface-mount-fuses/nano-2-fuses/451):0451007.MRL7A Nano2; generic2512 lands are slightly larger than6.1×2.69mm body and accept the end terminals. Confirm exact purchased fuse against manufacturer drawing before assembly; no unverified factory part code is assigned.
- [Murata ceramic capacitor series](https://www.murata.com/en-us/products/capacitor/ceramiccapacitor), [Yageo chip resistors](https://www.yageo.com/en/Product/Index/chip-resistors): explicit0805/2512 MPNs in parts.json. Sourcing stock is not certified.
